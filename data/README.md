# 공개 데이터

- `source-registry.yaml`: 정책 문서와 GFM 출처 메타데이터. `scripts/source_registry.py`로 재생성합니다.
- `institution-registry.yaml`: 정책 문서의 기관 ID·공식 도메인 검증 기준.
- `australia-pilot.yaml`: 공개된 호주 10건의 범위·공식 URL.
- `metadata/`: Markdown에서 재생성한 문서·관계·연표.
- `gfm/source-registry.json`: GFM의 원래 필드·검토 범위를 보존하는 projection.

원문 파일·취득 로그·추출 전문·내부 보관 경로는 공개 데이터에 포함하지 않습니다.
