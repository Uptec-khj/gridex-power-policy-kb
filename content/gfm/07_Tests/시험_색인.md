# GFM 시험 색인

시험 결과에는 최소한 `문서ID/판본`, `조항·쪽`, `EUT 경계`, `초기 P/Q·SOC`, `SCR·X/R`, `고장 조건`, `제어모드·SW 버전`, `측정·필터`, `판정식`, `원시데이터 해시`를 기록한다.

| 시험 | 주요 출력 | 대표 증빙 |
|---|---|---|
| 전압크기 계단 | P/Q 즉시응답, 내부전압, 정착·댐핑 | 모델 파형·시험성적서 |
| 위상각 계단 | Active Phase Jump Power, 전류한계 | 파형·계산시트·판정 로그 |
| RoCoF 램프 | 관성/FFR 분리, 주파수·P 응답 | 설정·원시데이터·필터 설명 |
| SCR 저하+고장 | trip 여부, P/Q 회복, 약계통 안정성 | EMT 케이스·모델버전·보고서 |
| 동기전원 상실/섬 | 주파수·전압 형성, 전력분담 | CHIL/현장 이벤트 기록 |
| 대칭·비대칭 FRT | 고장전류 크기·위상·순서성분 | 형식시험·EMT·현장검증 |
| 임피던스 스캔 | 주파수별 Z/Y, 공진·댐핑 | 스캔 설정·복소 데이터 |
| 블랙스타트 | 무전압 기동, 부하·변압기 여자 | 별도 서비스 시험·현장 시운전 |

## 한국 시험 근거의 현재 경계

- [KPX 시행 규칙](../02_Sources/Korea/KPX_Market_Rules_2026_04_29.md) 별표3 24.0은 상세 시험을 `계통평가세부운영규정`에서 정하도록 한다. 현재 공개된 [2026년 2월 23일자 규정](../02_Sources/Korea/KPX_Grid_Assessment_Detailed_Rules_2026_02.md)은 그보다 앞선 판본이고 GFM 용어가 없다. 따라서 후속 개정 시행본이 확인되기 전에는 GFM 시험 판정기준으로 인용하지 않는다.
- [계통해석 모델 제출 사전안내](../02_Sources/Korea/KPX_Inverter_Model_Submission_PreNotice_2026.md)의 제13장안은 단위 성능시험 기반 초기 모델, 현장 성능시험 후 최종 모델, 모델 파일·검증보고서·시험 시나리오·제어 파라미터 제출을 예고한다. 정상구간 정격 P/Q 대비 5% 이내 일치와 입력 후 5초 구간의 응답속도·상승/정착시간·오버슈트를 평가하지만, 2026년 3분기 규칙개정에 따라 바뀔 수 있는 **잠정안**이다.
- 위 모델 제출안의 RMS generic model `REPCGFMC1U`, `REGFMC1U` 경로는 GFM 모델 제출 가능성을 보여 주지만, 그 자체로 EMT 모델 검증이나 최종 GFM 성능시험과 동등하지 않다.
- [KTL 공식 안내](../02_Sources/Korea/KTL_PCS_Test_Service_KSGA_025_18_1.md)는 KSGA-025-18-1 시험서비스와 2 MW 이하 시험 가능 용량을 확인하는 근거다. 시험성적서, 제품인증, 계통연계 승인은 별도 증빙이다.
