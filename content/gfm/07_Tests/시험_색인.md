# GFM 시험 색인

시험 결과에는 최소한 `문서ID/판본`, `조항·쪽`, `EUT 경계`, `초기 P/Q·SOC`, `SCR·X/R`, `고장 조건`, `제어모드·SW 버전`, `측정·필터`, `판정식`, `원시데이터 해시`를 기록한다.

| 시험 | 주요 출력 | 대표 증빙 |
|---|---|---|
| 전압크기 계단 | P/Q 즉시응답, 내부전압, 정착·댐핑 | 모델 파형·시험성적서 |
| 위상각 계단 | Active Phase Jump Power, 전류한계 | 파형·계산시트·판정 로그 |
| RoCoF 램프 | 관성/FFR 분리, 주파수·P 응답 | 설정·원시데이터·필터 설명 |
| SCR 저하+고장 | trip 여부, P/Q 회복, 약계통 안정성 | EMT 케이스·모델버전·보고서 |
| 동기전원 상실/섬 | 주파수·전압 형성, 전력분담 | CHIL/현장 이벤트 기록 |
| 대칭·비대칭 FRT | 고장전류 크기·위상·순서성분 | 형식시험·EMT·현장검증 |
| 임피던스 스캔 | 주파수별 Z/Y, 공진·댐핑 | 스캔 설정·복소 데이터 |
| 블랙스타트 | 무전압 기동, 부하·변압기 여자 | 별도 서비스 시험·현장 시운전 |

## 한국 시험 근거의 현재 경계

- [KPX 시행 규칙](../02_Sources/Korea/KPX_Market_Rules_2026_04_29.md) 별표3 24.0은 상세 시험을 `계통평가세부운영규정`에서 정하도록 한다. 해당 규정 원문을 확보하기 전에는 수치 판정기준을 확정하지 않는다.
- [KTL 공식 안내](../02_Sources/Korea/KTL_PCS_Test_Service_KSGA_025_18_1.md)는 KSGA-025-18-1 시험서비스와 2 MW 이하 시험 가능 용량을 확인하는 근거다. 시험성적서, 제품인증, 계통연계 승인은 별도 증빙이다.
