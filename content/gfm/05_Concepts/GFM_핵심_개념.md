# GFM 핵심 개념

여러 공식 문서의 공통분모는 `짧은 과도 시간에 내부 전압 페이저를 거의 일정하게 유지하고 외부 계통 변화에 즉시 반응`하는 성능이다. 특정 제어 알고리즘(VSM, droop, dVOC 등) 이름만으로 적합성을 판단하지 않는다.

## 비교 축

- 전압원 거동: 전압원 뒤 임피던스와 유사한 단자 응답
- 주파수·RoCoF·위상 도약: 측정 기반 FFR과 고유/합성관성 응답을 구분
- 에너지·전류 제한: 한계 도달 전·진입 중·회복 후 안정성
- 전압·무효전력: 빠른 전압원 응답과 느린 정적 전압제어 분리
- 고장: FRT, 고장전류 크기·위상·순서성분, 회복
- 약계통·다중 인버터: 낮은 SCR과 상호작용·댐핑
- 모델: RMS/EMT 적용범위, 블랙박스 보호, 실물·현장 데이터 검증
- 독립운전·블랙스타트: 기본 GFM 정의와 별도 추가능력 여부
