# GFM 공개 지식창고 설계와 로드맵

## 저장소 경계

| 저장소 | 공개 범위 | 포함 | 제외 |
|---|---|---|---|
| 공개 Knowledge Base | Public GitHub·정적 문서 사이트 | 검증된 서지, 공식 링크, 자체 한국어 요약, 비교·추적성, 공개 검토 큐 | 제3자 PDF·표·그림·로고·인증서 사본·OCR 전문·전문 번역 |
| 개발 관리 | 별도 GitHub | 로드맵, 백로그, 변경기록, 수집기·스키마 개발 계획 | 공개 KB의 콘텐츠 원본 중복 |

## 정보 구조

1. 지역 허브에서 관할과 시장을 선택한다.
2. 문서 계열에서 현행·초안·대체·철회 관계를 본다.
3. 문서 노트에서 조항·쪽수와 요구사항을 확인한다.
4. 요구사항을 시험조건·판정기준·증빙 유형으로 연결한다.
5. 제품·프로젝트는 증서 원본 또는 발급기관 원장까지 확인된 경우에만 ‘증서 검증’으로 승격한다.

## 상태 모델

| 축 | 값 |
|---|---|
| 문서 상태 | 초안 / 공개회람·공청회 / 확정 / 대체 / 철회 / 미확인 |
| 적용 성격 | 의무 / 자발적 / 시장·계약 조건 / 연구·참고 |
| 접근 | 공식 전문 공개 / 유료 / 회원·접근 제한 / 서지만 확인 / 미확보 |
| 검토 | 후보 / 서지 확인 / 핵심 검토 / 사람 검수 완료 |
| 증빙 | 제조사 주장 / 적합성 선언 / 시험성적서 / 제품 인증서 / 계통연계 승인 / 서비스 참여 |

KSGA 개정 준비와 한전 공청회·기준 수립 이력처럼 공식 현행본과 다른 단계는 별도 레코드로 관리한다. 후속 문서가 확인되기 전에는 ‘발효’ 또는 ‘인증제도 시행’으로 승격하지 않는다.

## 실행 로드맵

| 단계 | 산출물 | 완료 기준 |
|---|---|---|
| GFM-0 | 공개 경계·메타데이터·상태 모델 | 본 문서와 템플릿에 반영 |
| GFM-1 | 국제 20건 + 한국 공식 2건 파일럿 | 공식 링크·판본·자체 요약·확보 상태, 깨진 내부 링크 0 |
| GFM-2 | 한국 규격 추적 | KSGA 개정안과 한전·KPX 개정 조항의 공식 원문·시행일 대조 |
| GFM-3 | 요구→시험→증빙 데이터화 | 조건·측정점·판정식을 출처 조항과 함께 구조화 |
| GFM-4 | 제품·프로젝트 증빙 원장 | 인증·시험·승인·서비스 참여를 구분하고 발급기관 검증 |
| GFM-5 | 변경 감지·검수 운영 | 무변경·개정·접근실패를 구분하고 편집 노트를 자동 덮어쓰지 않음 |

## 이번 공개본의 한계

- KSGA 현행 Ed1의 존재·범위는 공식 페이지에서 확인했으나 전문 조항별 재검토는 남아 있다.
- KSGA 개정 준비 상태는 사용자 제공 정보이며, 이번 조사에서는 개정안의 공식 공개 페이지를 찾지 못했다.
- 한전 규격은 정부가 의견수렴을 거쳐 성능요건을 마련했다고 발표한 단계까지 확인했다. 정확한 이용규정 개정 조항과 별표는 후속 대조 대상이다.
- 국내 GFM 제품 인증제도 또는 상호인정 체계의 존재를 이 자료만으로 단정하지 않는다.
