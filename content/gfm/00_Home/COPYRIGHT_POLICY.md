# 공개 보관함 저작권 정책

이 보관함은 공식 게시 페이지·공식 원문 URL·DOI·서지정보와 직접 작성한 한국어 요약·비교·분석을 공개 대상으로 삼습니다.

## 포함하지 않는 것

- 제3자 PDF 원본, 원문 표·그림·스크린샷·로고
- 인증서 사본, OCR 전문, HTML 복제, 전문 번역
- 유료 표준의 원문 또는 구매로 얻은 파일
- 문서를 대체할 정도로 세분화한 재구성

## 권리 처리

- 공개 열람 가능과 재배포 허용은 별개입니다.
- 원문에 명시적 재배포 허용 조건이 확인되지 않으면 `재배포 허용 상태: 미확인 또는 불가`로 기록하고 링크만 제공합니다.
- CQC 규칙과 FGW 부록처럼 원문에 복제·사용 제한이 명시된 자료는 재배포 불가로 처리합니다.
- IEEE 표준은 구매/구독 링크만 제공하며 원문을 포함하지 않습니다.
- 프로젝트 자체 콘텐츠 라이선스는 아직 선택하지 않았습니다. 제3자 자료에 프로젝트 라이선스를 일괄 적용하지 않습니다.

## 비공개 원문 보관과 공개 링크

2026-09-11 사용자 지시에 따라 취득 가능한 원문은 실제 비공개로 확인된 개발 저장소에 보관하고, 공개 사이트에는 공식 게시·원문 링크와 자체 작성 요약·분석을 제공합니다. 비공개 원문 경로·사본·전문 추출 색인은 공개 배포에 포함하지 않습니다.

개발 저장소의 Private 여부와 접근·저장 조건을 확인한 뒤 원문을 취득합니다. 확인 당시 개발 저장소는 Public이므로 현재 원문 업로드는 보류 상태입니다. 유료·접근제한 원문은 해당 권한·조건 확인 전 취득하지 않으며 원문 보관을 완료했다고 표시하지 않습니다.
