# 대표 요구→시험→증빙 연결 예제

## 예제 A — 약계통에서 GFM 안정성(AEMO)

| 단계 | 추적 내용 |
|---|---|
| 요구 | 전압원 거동을 유지하고 약계통·고장 후 안정적으로 운전 |
| 근거 | [AEMO 자발적 사양](../02_Sources/Australia/AEMO_2023_Voluntary_Spec.md) §2.3; [시험 프레임워크](../02_Sources/Australia/AEMO_2024_Test_Framework.md) §3.6 |
| 시험 | Testbench 1, 초기 SCR 20·100% 출력; SCR 10→3→2→1.5→1.25, 각 단계 6-cycle 2상지락·fault depth ≥0.5 pu |
| 판정 | SCR 1.25까지 장시간 trip/출력저하 없이 P·Q가 제어되고 안정 |
| 예상 증빙 | 입력 모델 버전, 시험설정 파일, 파형·계산값, pass/fail 보고서, 모델검증 보고서 |
| 효력 한계 | AEMO 2024 자발적 모의시험 증빙이며 NER 접속승인·제품인증을 자동 부여하지 않음 |

## 예제 B — 독일의 제품/설비/운전허가 체인

| 단계 | 추적 내용 |
|---|---|
| 요구 | VDE FNN v2.1의 계통형성·Momentanreserve 요구 |
| 단위 검증 | 측정, 모델, 모델검증 및 FGW TR 8 평가에 따른 단위/구성품 인증 |
| 설비 검증 | 발전단지 인증, 필요 시 extra-high-voltage 확장 절차와 qualified plant report |
| 운전 증빙 | 임시 운전허가 → 현장 측정·적합성 선언 → 계통운영자 최종 운전허가 |
| 근거 | [VDE FNN v2.1](../02_Sources/Germany/VDE_FNN_2026_v2_1.md) §5.5~5.7; [FGW 부록](../02_Sources/Germany/FGW_TR8_Beiblatt_10_1.md) |
| 효력 한계 | 인증기관 증서와 계통운영자 허가, 시장의 Momentanreserve 계약은 각각 별도 확인 |

## 예제 C — 중국 CQC GFM PCS 제품인증

| 단계 | 추적 내용 |
|---|---|
| 대상 | 10(6) kV 이상 전기화학 저장발전소용 GFM PCS의 병렬성능·시뮬레이션 모델 인증 |
| 신청 단위 | 원칙적으로 제품 모델별; 동일 제조자·동일 모델이라도 생산공장이 다르면 별도 단위 |
| 시료 | PCS 1대, 반실물 제어기 1대, 버전 포함 소프트웨어, PCS EMT 봉인모델 1세트 |
| 평가 | 형식시험 + 초기공장검사 + 인증결정 + 사후감독 |
| 증빙 | 지정 검사기관의 시험보고서, 공장 일관성 기록, CQC 인증서(5년, 감독으로 유지) |
| 근거 | [CQC19-461262-2024 v1.3](../02_Sources/China/CQC19_461262_2024_v1_3.md) §1~9 |
| 효력 한계 | 인증서가 특정 프로젝트의 계통연계 승인·시장참여를 자동 증명하지 않음 |
