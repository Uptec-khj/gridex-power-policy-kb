# 증빙 유형 구분

| 유형 | 무엇을 증명하는가 | 다른 유형으로 자동 대체? |
|---|---|---|
| 제품/단위 인증 | 특정 모델·생산단위가 인증규칙을 충족 | 아니오 |
| 형식시험 성적서 | 정해진 시료와 조건의 시험 결과 | 제품인증·현장승인 아님 |
| 모델검증 보고서 | 모델이 실물/현장 응답을 재현 | 모든 운전조건의 적합성 아님 |
| 설비/발전단지 인증 | 집합설비와 계통 접속점 성능 | 개별 제품인증과 범위 다름 |
| 적합성 선언 | 규정된 전체 절차의 완료 선언 | 계통운영자 승인과 구분 |
| 계통연계 승인/운전허가 | 특정 위치·계통조건에서 접속·운전 허가 | 타 시장 이전 불가 |
| 보조서비스 참여/계약 | 시장서비스 성능·가용성 조건 충족 | 제품 GFM 인증과 구분 |

제조사 보도자료만으로 확인한 주장은 `제조사 주장`이며 실제 증서 검증으로 표시하지 않는다.
