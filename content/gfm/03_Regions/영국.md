# 영국 GB

GC0137은 GB Grid Forming(GBGF) 능력을 Grid Code에 비의무 기술사양으로 구현해 시장·계약 서비스 제공의 기반을 만들었다. Issue 4 Guidance Note는 시뮬레이션, 모델검증, FAT와 현장시험의 실무 연결을 설명한다. GC0163은 가상임피던스 구현방식 제한을 제거하고 결과 성능 중심으로 정리했다.
