# KSGA GFM 단체표준 개정안 추적

사용자 제공 정보에 따르면 `KSGA-025-18-1`의 개정안이 준비 중이다. 2026년 9월 11일 [현행 Ed1 공식 페이지](https://ksga.org/sgstandard/lib/all/enactment/view.do?seq=2693), [단체표준 개발현황](https://ksga.org/sgstandard/lib/all/development.do), [GFM 작업반 운영 페이지](https://ksga.org/sgstandard/activity/3/19/operation.do)를 다시 확인했다.

| 공식 경로 | 공개 확인 결과 | 해석 |
|---|---|---|
| 현행 표준 페이지 | 2022-11-17 제안 승인부터 2023-12-21 Ed1 제정까지의 이력만 표시 | 현행 Ed1과 최초 제정 절차는 확인됨 |
| 단체표준 개발현황 | 목록 내용은 로그인 후 확인 가능 | 비로그인 공개 화면만으로 개정 단계·판본 확인 불가 |
| GFM 작업반 운영 | 공개 표에 게시 내용 없음 | 개정이 없다는 뜻이 아니라 공개 근거가 없음 |

따라서 `개정 준비 중`은 계속 사용자 제공 정보로 유지하며, NP·WD·공개회람·위원회 심의·개정 확정 중 어느 공식 단계인지는 공개적으로 확인되지 않은 상태다. 공개 화면의 부재나 로그인 제한을 개정안 부존재로 해석하지 않는다.

## 승격 조건

- KSGA 표준화 개발현황 또는 공개회람 게시물의 공식 URL
- 개정안 식별자·판본·문서 단계와 날짜
- 변경 범위와 현행 Ed1의 대체 관계
- 이용조건과 전문 접근 상태

근거가 확보되면 [현행 단체표준](../02_Sources/Korea/KSGA_025_18_1_2023_Ed1.md)과 별도 원문 노트로 등록한다. 준비 중이라는 사실만으로 개정 완료·시행·인증제도 변경으로 표시하지 않는다.
