# GC0137

Grid Code에 GBGF 능력의 비의무 기술사양과 데이터·적합절차를 추가해 추가적인 계통안정도 서비스를 제공할 수 있게 했다. 2022-02-14 구현됐으며 제품인증제도 자체가 아니라 Grid Code와 상업서비스 참여를 잇는 제도다. 실제 적용은 현행 Grid Code 판본과 [Issue 4 Guidance](NESO_GFM_Guidance_Issue4.md)를 함께 확인한다.
