# Grid Forming Guidance Note Issue 4

Grid Code Issue 6 Revision 36(2025-12-12)에 근거해 GC0137과 GC0163을 반영한다. 모델 제출, 검증된 모델을 이용한 사전 시뮬레이션, FAT 예상사항, 현장시험과 데이터 제출을 연결한다. GBGF 서비스는 의무가 아니라 시장약정으로 제공된다.

주요 확인값: GFM 능력을 제공하는 PPM은 rolling 500 ms 기준 2 Hz/s RoCoF까지 trip 없이 견뎌야 하며 일반 PGM은 1 Hz/s다. GBGF-I는 전압원 뒤 임피던스로 동작하고 Active RoCoF/Phase Jump/Damping Power 등을 제공하며, 문서에는 최소 단락레벨 0 MVA 운전 문구가 있다. 이 값은 다른 시장의 SCR 시험값과 직접 등가로 해석하지 않는다.

문서 자체가 전문가그룹의 추가 Grid Code 수정 전 임시 지침임을 밝히므로 판정에는 최신 Grid Code 조항을 우선한다.
