# 2026년 4월 29일 시행 전력시장운영규칙의 GFM 조항

전력거래소는 2026년 4월 28일 총 9건의 규칙 개정을 공고했고, 기후에너지환경부장관 승인일은 4월 24일, 시행일은 4월 29일이다. 공식 전문에는 GFM과 GFM 인버터의 정의, GFM 모드 급전지시, 기술특성·실시간 상태자료 제공, 중앙계약전기저장장치의 성능 및 유지·관리 의무가 신설되었다.

## 요구사항 색인

| 위치 | 핵심 내용 | 증빙 관점 |
|---|---|---|
| 제1.1.2조 159·159의2 | 독립 전압원으로 전압·주파수를 형성하고 외란 중 동기를 유지하는 GFM 및 해당 인버터 정의 | 제품 명칭이 아니라 규칙상 기능 정의에 대한 적합성 필요 |
| 제5.3.1조①10 | 전력거래소 급전지시 대상에 GFM 인버터 모드 운전 추가 | 운전모드 상태·지시 이행 로그 |
| 제5.8.4조⑨ | 사업자는 기술특성 자료와 실시간 운전상태를 제공 | 승인자료, 원격감시·통신 데이터 |
| 제15.3.2조⑨ | GFM 기반 중앙계약전기저장장치의 성능·유지·관리 기준을 별표3에 연결 | 규칙-시험규정-제출자료 추적표 |
| 별표3 24.1 | 주파수 변동 시 즉각적 유효전력 공급·흡수로 관성 응답 제공 | 시험방법·수치 판정은 계통평가세부운영규정 확인 필요 |
| 별표3 24.2 | 전압 변동 시 보호계전기 동작을 지원하는 특성의 고장전류 제공 | 고장 조건·전류 크기/위상·보호협조 자료 필요 |
| 별표3 24.3 | 단자전압 위상 급변에도 탈락·정지 없이 동기 유지 | 위상도약 시험과 통과기준 필요 |
| 별표3 24.4 | 낮은 SCR 약계통에서 안정적 전력 공급 | SCR·X/R·계통임피던스 조건 필요 |
| 별표3 24.5 | 계통 운영상 필요 시 무전압 상태 자체기동 및 전압 형성 | 모든 설비의 일률 의무가 아닌 조건부 요구 |
| 별표3 25.1~25.3 | 성능검증, 결과 제출, 변경 사전통보, 운전제한·시정조치 | 검증보고서, 버전·파라미터 변경기록, 개선계획 |

## 판정 경계

별표3 24.0은 성능시험 세부사항을 `계통평가세부운영규정`에서 정하도록 위임한다. 따라서 위 조항만으로 관성 정수, RoCoF, 위상도약 각도, 최소 SCR, 고장전류 크기와 지속시간 같은 수치 합격기준을 만들지 않는다. 해당 세부운영규정의 판본과 조항을 확보하기 전까지 수치 항목은 `미확인`이다.

공식 PDF는 검토 목적으로만 임시 열람했으며 저장소·ZIP에는 포함하지 않는다. 본 노트는 원문을 대체하지 않는 조항 색인과 자체 요약이다.
