# 제품·프로젝트 증빙 검증 대장

이번 파일럿은 실제 제품 인증서를 검증하지 않았다. 향후 항목은 아래 상태만 사용한다.

| 상태 | 의미 |
|---|---|
| 제조사 주장 | 보도자료·브로셔만 확인 |
| 기관 발표 확인 | 인증/시험기관의 발표 페이지 확인, 증서 미대조 |
| 증서 서지 확인 | 인증번호·모델·발행/만료·기관 원장 대조 |
| 증서 원본 검증 | 증서 사본의 진위·범위·부속서·취소상태 확인 |
| 프로젝트 승인 확인 | 계통운영자/망사업자의 특정 접속점 승인 확인 |
| 서비스 참여 확인 | 시장운영자 등록·계약·실적의 공개 근거 확인 |

## 필수 필드

제조사, 모델/펌웨어, 인증번호, 인증규칙·판본, 시료/정격 범위, 생산공장, 시험기관·인정범위, 발행·만료·정지상태, 원장 URL, 프로젝트 위치·접속점, 검증일, 공개 가능성.
