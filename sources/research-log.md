# 초기 공식 자료 조사

조사 기준일: 2026-09-09 (Asia/Seoul). 이 문서는 전체 공개자료의 완전한 인벤토리가 아닙니다.

확인 경로: 산업부 보도자료·공고, KPX 전력수급기본계획 및 장기수요전망 게시판, 기후부 보도자료, 한전 사보. 검색어는 차수별 전력수급기본계획·확정·수정 공고·장기 수요전망·장기 송변전설비계획입니다. 민간 페이지는 공식 URL 발견에만 참고하며 콘텐츠 근거로 채택하지 않았습니다.

확인된 사실:

- 제10차 확정 발표는 2023-01-12, PDF 표지 공고일은 2023-01-13입니다.
- 제11차 최초 공고는 2025-169호, 2025-02-21입니다. 후속 수정 공고는 2025-238호, 2025-03-13입니다.
- KPX 자료실의 제11차 PDF를 열면 수정 공고 표지가 나옵니다. 최초 공고의 원본으로 사용할 수 없습니다.
- 기후부 12차 착수 게시물의 이전 boardMasterId=1 경로는 404였고, 현재 939 경로에서 같은 게시물 ID·제목·날짜를 확인했습니다.
- 12차 4·5차 토론회 안내는 2026-08-15, 6차 안내는 2026-08-20 게시되었습니다. 개최 예고를 실제 발표 결과로 사용하지 않습니다.
- 산업부 첨부 경로 일부는 HTTP 오류로 실패했습니다. 본문 HTML은 보존했고 파일 해시는 조작하지 않았습니다.
- 한전 구 게시판의 제10차 계획 후보 링크는 접근 실패했습니다. 한전 사보 해설 2건을 보조 문서로 보존하되 전문 확보 과제로 남겼습니다.

출처 URL과 실제 획득 경로·해시는 seed-documents.yaml 및 data/metadata/acquisitions.json을 참조합니다. 변경·추가되는 문서는 다음 조사에서 확인하며 자동 모니터는 아직 설정하지 않았습니다.
