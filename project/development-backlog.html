전체 로드맵 · 개발 기록

우선순위 P0는 근거·데이터 품질, P1은 탐색·운영 개선, P2는 확장 기능입니다. 체크는 실제 완료 후 표시합니다. 자료원별 URL·다운로드 실패 이력은 GitHub의 sources/backlog.yaml에서 관리합니다.

완료 · v0.3

  • DEV-001 · 원문 페이지 검색 — PDF 추출, 출처·해시·물리적 쪽수, 빈 페이지 보고, 공개 검색. 완료 기준: 의미 있는 자동 테스트와 실제 원문 검색 통과.
  • DEV-002 · Obsidian 개발 관리 — 로드맵·백로그·개발 기록·작업 템플릿 연결. 완료 기준: Wiki Link 검증과 Quartz 공개 페이지 생성.

완료 · v0.4

  • TECH-001 · 기술 문서 범위 확장 — 현장시험·송전계통 연계 기준 부록·모델 규정 개정안 3건, 표준·템플릿·검색 필터.
  • DATA-001A · 최초 공고 복원 — p11-final PDF 표지 2025-169호 확인·보존.
  • DATA-002A · 제12차 5월 잠정안 — p12-demand-draft-20260519 PDF 원표와 시나리오 수치 대조(AI).
  • QA-001 · 검수 작업목록 — review-queue 자동 목록과 검수 양식. 실제 사람 검수는 대기.
  • REL-001A · 관계 데이터 — 유형·공식 근거·연결 판단 설명을 색인에 보존, 기존 Wiki Link 유지.

완료 · v0.5

  • PLAN-001 · 종합·재생에너지 계획 — 제3차 에너지기본계획, 제5차 신재생에너지 계획, 제1차 재생에너지 계획 전문과 Markdown 등록. energy-renewable-plans.
  • SEARCH-003 · 계획 계열 분리 — 메타데이터 조합 검증과 웹·CLI 검색 필터. 같은 차수의 다른 계획 분리.

준비된 작업

국제 확장의 상세 의존성과 완료 기준은 international-roadmap에 기록한다. 아래 작업은 계획이며 자동 수집은 아직 활성화하지 않았다.

  • GLOBAL-000 · 국제 확장 설계 — 국가 메뉴, 공식 자료원 후보, 관할·버전·다국어 표준 방향, 증분 수집 운영 계획.

  • P1 / GLOBAL-001 · 국가 탐색·국제 Metadata — G1. 국내 37건 호환 유지, 지역 허브·관할·언어·문서 종류와 검색 필터. 해외 파일럿의 선행 작업.

  • P1 / GLOBAL-002 · 호주 6건 파일럿 — G2. G1 이후 AEMO/AEMC, NEM/WEM 구분, 원문 근거와 개정 이력.

  • P1 / GLOBAL-003 · 미국 6건 파일럿 — G3. 호주 경로 검증 후 DOE/FERC/NERC 중심, 연방·지역 및 표준·가이드 구분.

  • P1 / GLOBAL-004 · 유럽·중국 각 6건 — G4. EU·국가 관할, 중국어 검색·표준 대체·전문 공개 범위 검증.

  • P1 / GLOBAL-005 · 지속 발견·변경 큐 — G5. OPS-001과 통합해 중복 방지·원본 교체·권리 판정·실패 복구 검증 후 정기 실행 설정.

  • P2 / GLOBAL-006 · 국제 비교·다국어 RAG — G6. 20개 평가 질문, 관할·버전·수치 정의를 보존한 근거 검색.

  • P0 / DATA-001 · 첨부 복원 — 산업부 오류 경로를 공식 재게시 경로와 대조. 파일 확보 전에는 해시·전문 내용 생성 금지. 연결: collection-status.

  • P0 / DATA-002 · 제12차 실제 발표자료 — 5월 잠정안 이후 수요 재전망과 각 토론회 발표·결과 확보. 연결: p12-forum3, p12-forum45, p12-forum7.

  • P0 / QA-002 · 사람 검수 실행 — review-queue의 실제 검수자·날짜·판단 근거 기록.

  • P1 / REL-001B · 관계 탐색 화면 — 추가한 관계 유형을 정책 문서에 확대하고 그래프에서 구분.

  • P1 / NUM-001 · 핵심 수치 데이터 — 기준수요/목표수요, 발전단/판매단, 총량/증가분을 구분한 구조화 데이터와 비교 화면. 원표 대조가 선행 조건.

  • P1 / OPS-001 · 수집 재시도·변경 감지 — 실패 원인별 재시도, 원본 해시 변경 후보 보고, 편집 문서 자동 덮어쓰기 방지.

  • P1 / OPS-002 · 배포 자동화 — 현재 수동 발행 절차를 유지하면서 실행 권한이 준비되면 저장소의 워크플로 예제를 활성화. 성공·실패·재배포 경로 검증.

  • P2 / RAG-001 · 평가 질문 세트 — 차수·버전·수치·예정 행사·근거 부재 질문과 기대 출처를 저장.

  • P2 / RAG-002 · 혼합 검색 — 키워드 검색의 누락 사례를 먼저 측정하고 벡터 검색·관계 확장 추가.

  • P2 / RAG-003 · 생성형 답변 — 출처 페이지와 검증 상태 인용, 근거 부족 시 유보. 검색 평가와 API 운영 방식 결정 후 진행.

  • P0 / TECH-002 · 기술기준 전문 — 한전 연계기준 전체와 최신 개정 이력, 후속 모델 규칙 확정 공고 확보. technical-documents.

추가 작업

  • DIFF-001 · 제11차 공고 차이 — p11-final과 p11-amend PDF 확보 완료. 페이지 대응·표·숫자 차이 분석과 사람 검수 진행 가능.
  • OCR-001 · 이미지 원문 검색 — extraction-status의 텍스트 없는 페이지 중 실제 이미지 문서를 선별한 뒤 OCR 품질 기준·도구 결정. 빈 페이지를 모두 OCR 실패로 분류하지 않는다.
  • RIGHTS-001 · 원문별 이용조건 — 출처 표시·변경 허용·공공누리 적용 범위를 각 원문에서 확인. 코드 라이선스를 행정자료에 적용하지 않는다.
