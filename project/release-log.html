개발 로드맵 · 개발 백로그

국제 확장 설계 · 2026-09-09

  • 국가별 전력정책·기술기준 로드맵과 공식 자료원 후보 11개를 작성하고 전체 로드맵·백로그에 연결.
  • 국가/지역 메뉴, 적용 관할·전력시장·언어·버전 표준, 해외 24건 파일럿, 증분 수집·권리 확인·검수·공개 흐름을 설계.
  • AEMC·EUR-Lex·TYNDP의 직접 접근/본문 추출 한계를 기록. 자료원 후보는 비활성 상태이며 수집 가능성·이용조건 검증이 남아 있음.
  • 이번 변경은 계획 문서만 해당. 해외 문서·국가 탭·수집기·예약 실행은 구현하지 않았으며 공식 자료 수는 37건 유지.

v0.5 · 에너지·재생에너지 기본계획 · 2026-09-09

  • 제3차 에너지기본계획, 제5차 신재생에너지 기본계획, 제1차 재생에너지 기본계획 전문 PDF와 Markdown 3건 추가.
  • 공식 자료 37건, 고유 첨부 36개(PDF 25개), 전체 PDF 페이지 757쪽. 검색 가능한 텍스트 755쪽, 빈 면 2쪽도 보존. 파일 처리 실패 0건.
  • 계획 계열 안내에서 전력수급·송변전·기술 문서로 연결. 관계 141개, Timeline 40개, 편집 청크 370개.
  • 계획 계열별 차수·분류 조합을 검증하고 웹과 CLI에 계열별 원문 필터 추가. 같은 차수의 다른 계획 혼합 방지.
  • 신재생/재생, 최종에너지/발전량 비중, 누적 설비용량, 발표 당시 목표를 구분. 신규 재생에너지 계획의 지방정부 별첨(안)과 법 시행 예정일을 명시.
  • 자동 테스트 22개 통과. 새 계획 계열·잘못된 차수 조합·동일 차수의 다른 계열 제외를 검증.
  • 남은 범위: 에너지기본계획 1·2차와 기존 신재생 계획 1~4차, 후속 종합정책·법적 계획 체계 변화, 사람 검수.

v0.4 · 재생에너지 기술 문서와 근거 보강 · 2026-09-09

  • 공식 문서 34건, 고유 첨부 33개(PDF 22개), 원문 페이지 534쪽으로 확장.
  • KPX에서 제11차 최초 공고 PDF(표지 2025-169호) 확보. 수정본과 별도 해시로 보존하며 본문 비교는 후속 작업.
  • 제12차 2026년 5월 수요 전망(안) 원표 확보. 2040년 시나리오 수치를 PDF p.6과 대조(AI); 확정 전망으로 표시하지 않음.
  • 한전 현장 특성시험 부록6, KPX 시험 결과 제출 안내, 계통해석 모델 규정 개정안 3건을 기술 문서로 연결.
  • 계획 차수가 없는 기술 문서의 기준번호·개정일·시행일·적용 범위·확보 범위 표준과 전용 템플릿 추가.
  • 원문 검색의 기술 문서 필터, RAG 색인의 기술 메타데이터, 근거를 갖는 관계 유형 데이터 추가. 관계 총 127개, Timeline 37개, AI 편집 청크 340개.
  • 검수 대기 목록을 Markdown 상태에서 생성하고 사람 검수 양식 제공.
  • 자동 테스트 18개 통과: 기존 해시·출처·링크 검사, 기술 문서 차수 분리, 미확정 시행일 방지, 관계 근거 필수, 원문 검색 포함·제외 확인.
  • 남은 한계: 한전 기술기준 전체 전문 미확보, 모델 규칙 확정본 미확인, 수치 구조화·공고 본문 비교·사람 검수 대기. 그래프 선의 유형별 시각화와 생성형 답변은 후속 단계.

v0.3 · 원문 검색과 개발 관리 · 2026-09-09

상태: 구현·로컬 검증 완료.

  • Obsidian 로드맵·백로그·개발 기록·작업 템플릿 추가.
  • 16개 문서에 첨부된 고유 PDF 17개, 376쪽의 원문 텍스트와 출처·쪽수 색인 생성. 공식 문서 총수는 30건으로 유지.
  • 공개 검색의 차수·문서 단계 필터, 한국어 띄어쓰기·숫자 쉼표 정규화, 공식 PDF·게시물·보존본 링크 제공.
  • 글자가 적은 11쪽을 별도 표시. 포스터 제목만 추출되는 실제 사례를 확인했고 OCR 완료나 전체 텍스트 복원을 주장하지 않는다.
  • 테스트 13개 통과. 추가한 추출 테스트 5개를 최종 코드에서도 재확인. 실제 PDF 수치·쪽수 검색, 차수 제외, 기존 한글 검색·그래프·Wiki Link 검증 통과.
  • 브라우저에서 송변전 61183 → 11차 확정 계획 PDF p.14를 확인하고 10차 필터에서는 제외됨을 확인.
  • 파생 색인이 Git 제외 설정 때문에 배포에서 누락되는 문제를 수정하여 명시적 Quartz 출력 단계 추가.
  • 남은 한계: OCR·표 구조화·원문 추출 사람 검수·벡터 검색·생성형 답변 미구현.

v0.2 · 공식 자료 30건 · 2026-09-09

  • 공식 문서 13건에서 30건으로 확장. 동일 파일 형식과 허브는 문서 수에서 제외.
  • 10·11차 장기 송변전설비계획 전문, 11차 별도 발표자료, 환경평가·공청회·위원회·12차 토론회 자료 확보.
  • 원본 첨부 28개, 문서 관계 115개, Timeline 사건 33개, AI 편집 청크 300개.
  • 한전 첨부 어댑터 추가. 테스트 8개·한글 검색·그래프·검수 표시·공개 URL 확인.
  • 남은 한계: 산업부 일부 첨부 오류, 12차 실제 발표자료 미확보, 사람 검수 대기.
