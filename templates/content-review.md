## 원본과 버전

- 대상 문서:
- 원본 URL / SHA-256:
- 게시일 / 제·개정일 / 시행일:
- 확보 범위: 전문 / 발췌 / 안내 / 개정안

## 확인 항목

- [ ] 공식 발행기관·게시기관·문서 버전 확인
- [ ] 적용 대상·지역·전압·설비 유형·운전 조건 확인
- [ ] 수치의 연도·단위·정의·시나리오·PDF 쪽수 확인
- [ ] 요약의 각 주장과 원문 대조
- [ ] 관련 문서·개정 관계와 근거 확인
- [ ] 원문 이용조건 확인

## 검수 결과

사람이 직접 검수를 마친 뒤 검수자·날짜·판단 근거를 기록합니다. AI가 이 양식을 작성하거나 원문을 추출했다는 이유로 검수 완료 처리하지 않습니다. 모든 필수 확인 후에만 대상 문서의 verification_status, summary_review_status, reviewed_by, reviewed_date를 함께 갱신합니다.
