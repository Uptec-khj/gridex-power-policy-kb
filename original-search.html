공식 PDF 원문 검색

  • 검색
  • 원문검색

공식 PDF에서 자동 추출한 텍스트를 찾습니다. 표·각주는 원문에서 확인하세요.

검색어를 입력하세요. 검색할 때 원문 색인을 불러옵니다.

보존한 공식 PDF의 텍스트를 검색합니다. 기존 왼쪽 검색창은 Markdown 편집 문서를 찾고, 위 검색 화면은 PDF 안의 페이지를 찾습니다.

검색 예: 송변전 61,183, 72.8, 전력수요, 석탄발전. 여러 단어를 입력하면 모든 단어가 문서 제목 또는 해당 페이지에 포함된 결과를 표시합니다. 차수와 문서 단계로 범위를 좁힐 수 있습니다.

검색 결과를 읽는 법

쪽수는 PDF 파일의 첫 페이지를 1로 센 값입니다. 문서에 인쇄된 쪽수와 다를 수 있습니다. 검색 텍스트는 자동 추출 결과이며, 표의 열·행·각주는 공식 PDF와 대조하세요. 공식 다운로드 서버가 PDF 뷰어를 제공하지 않으면 표시된 쪽수를 직접 찾아야 합니다.

이미지·스캔 페이지에서 글자를 인식하는 OCR은 아직 적용하지 않았습니다. PDF를 확보하지 못한 문서와 이미지 속 글자는 검색에서 빠질 수 있습니다. 제목만 추출된 포스터도 있으므로, 텍스트가 있는 페이지의 모든 글자가 검색되는 것은 아닙니다. 추출 현황에서 범위를 확인하세요.

검색어는 외부 AI 서비스로 전송하지 않고 브라우저에서 처리합니다. 추출 텍스트를 AI가 요약한 문장과 혼합하지 않습니다.

국가·관할·전력시장·원어·문서 종류 필터를 함께 사용할 수 있습니다. 선택과 검색어는 주소에 저장됩니다. 해외 원문은 아직 수집 준비 중이므로 해당 지역은 결과가 0건입니다. PDF 없는 문서까지 찾으려면 국가별 문서 찾기를 이용하세요.

기술 자료는 문서 범위에서 기술 문서를 선택하세요. 한전 부록6은 PDF 쪽수와 인쇄 쪽수가 다릅니다(PDF p.1 = 인쇄 p.89). 기술 문서 안내에서 전체 기준 확보 여부와 개정안 상태를 먼저 확인할 수 있습니다.
